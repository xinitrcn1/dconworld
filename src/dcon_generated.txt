// DataContainer definitions: every game object lives here.
//
// Sizes are hard bounds (DataContainer allocates them up front), chosen as
// powers of two a little above what vanilla Rain World needs, leaving room
// for Downpour/Watcher content:
//   regions 14 (+2 pseudo), +31 Watcher, +10 Downpour -> 128
//   rooms 760                 -> 2048
//   tiles 3264886             -> 8388608 (2^23)
//   room cameras 1714         -> 4096
//   placed items 511          -> 1024
//   shortcuts 6266            -> 16384
//   exits/dens 2957 (8039 with Watcher) -> 16384
//   room nodes 3393           -> 16384 (+ ~460k connectivity entries
//     pooled, a few million with Watcher)
//   players: co-op up to 4    -> 8
//   palettes ~50 files        -> 128
//   items (rocks): placed + random spawns persist in every visited room,
//     ~3000 once all 760 rooms were visited, ~11000 with Watcher -> 32768
//   physical objects / body chunks: players + items -> 32768 / 65536
//   region gates ~20          -> 64
//   music triggers ~80 (+MSC/Watcher) -> 512
//   centipedes: a few per realised room -> 64 (17 chunks, 136 push
//     connections each at most, within the chunk/connection bounds)
//   rot placed objects: 193 vanilla (229 with Downpour) -> 4096, leaving
//     room for Watcher's rot regions
//   rot: 18 vanilla rooms with rot (27 with Downpour) -> 256 systems;
//     6584 bulbs (806 in the worst room), 618 tubes -> 65536 / 16384;
//     Watcher: 159 rooms, 37647 bulbs, 2199 tubes, 220k rot grid cells
//   shortcut path tiles pooled (~6266 paths)
//   decals: 6152 CustomDecals (vanilla + Watcher) -> 16384
//   placed things (fruit, mushrooms, molds, cobs, pearls, mud, terrain
//     handles): ~3700 vanilla + Watcher -> 8192
//   warp points: 85 Watcher rooms have one or two -> 1024, as many targets
//
// Tags: `scenario` = static world data loaded from the game files,
//       `save` = simulation state.
